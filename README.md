# Subscription Management System

A unified platform to manage subscription-based businesses, built for the Odoo Virtual Hackathon.

The system simplifies the complete subscription lifecycle, including customer management, product and plan creation, subscription tracking, automated recurring billing, invoice generation, discount management, payment tracking, and revenue analytics.

### Key Features
- User authentication and role-based access
- Product and subscription plan management
- Subscription lifecycle management
- Automated recurring invoices
- Discount and tax management
- Payment tracking
- Revenue analytics dashboard

### Tech Stack
- Frontend: React.js
- Backend: FastAPI
- Database: SQLite / PostgreSQL
